# HANDSDASH 🥊

**Got beef? Bring the gloves.**

A responsive interactive concept website for voluntary, supervised sparring and conflict-resolution sessions.

## Demo

Open `index.html` in a browser. The service selections and sample checkout are interactive, but no real bookings or payments are enabled.

## Publish with GitHub Pages

1. Create a public GitHub repository named `handsdash` under the `clearmyrecord` account.
2. Upload the files from this package to its `main` branch (with `index.html` at the repository root).
3. In repository Settings → Pages, set **Deploy from a branch** and choose `main` / `(root)`.
4. When deployment completes, visit `https://clearmyrecord.github.io/handsdash/`.

This is a fictional prototype. The interface does not facilitate violence or real hired assaults.
